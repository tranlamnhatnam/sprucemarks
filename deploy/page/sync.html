Đồng bộ đám mây & Dữ liệu
Tự động đồng bộ đám mây (Chromium Cloud Sync) Đang hoạt động
Tự động đồng bộ quy tắc sắp xếp và cài đặt giữa các thiết bị thông qua tài khoản Google / Chromium mà không cần máy chủ riêng.
Chuyển giao nhanh qua mã cấu hình (Quick Code)
Mã hóa cài đặt thành chuỗi ký tự Base64 ngắn để copy/paste nhanh qua tin nhắn mà không cần tải file.
Sao lưu file cấu hình (Backup JSON)
Xuất toàn bộ tùy chọn sắp xếp và cài đặt hiện tại ra file JSON trên máy tính.
Khôi phục từ file (Restore JSON)
Tải lên file JSON cấu hình đã lưu trước đó để áp dụng ngay lập tức.
Đặt lại cài đặt gốc
Khôi phục tất cả cài đặt và quy tắc sắp xếp về trạng thái ban đầu của tiện ích.
